## ✨ Features
* Responsive Design (Mobile aur Desktop dono par chalega)
* Smooth animations aur transitions
* Image Lightbox view (badi screen par dekhne ke liye)

## 🛠️ Tech Stack Used
* **HTML5** - Structure ke liye
* **CSS3** - Styling aur layout ke liye
* **JavaScript** - Interactivity aur image handling ke liye
